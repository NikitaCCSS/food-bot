# Telegram-бот для учета продуктов

Мой первый проект на Python. Бот позволяет вести учет расходов на продукты прямо в Telegram.

## Функционал:
- Добавление покупок (с ценой и датой).
- Просмотр последних 5 покупок и общей суммы.
- Статистика: Топ-3 самых частых продуктов.
- Расходы за сегодня.
- Красивый график расходов (библиотека matplotlib).
- Удаление покупок.

## Технологии:
- Python 3
- pyTelegramBotAPI (telebot)
- JSON (для хранения данных)
- Matplotlib (для графиков)

## Как запустить:
1. Установите зависимости: `pip install telebot matplotlib`
2. Вставьте свой токен в файл `food_bot.py` (строчка `YOUR_TOKEN_HERE`).
3. Запустите: `python food_bot.py`
